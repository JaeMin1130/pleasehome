# Skill: patch-correction

이 스킬은 이미 적재된 기존 공고에 대한 정정공고(예: `[정정공고]...`)가 접수된 경우, 데이터를 전량 삭제 후 재적재하지 않고 기존 데이터베이스(`public_housing.db`)의 정합성을 유지하면서 변경된 사항만 안전하게 덮어쓰는 부분 업데이트(Partial Update/Patch)를 수행하기 위한 가이드라인입니다.

---

## 1. 작동 원리 및 단계별 수행 지침

### 1단계: 정정 대상 및 기적재 여부 판별
* 새로 수집된 공고 중 제목에 `[정정공고]` 키워드가 포함된 대상을 분류합니다.
* 공고 ID 또는 고유 키워드를 기반으로, 해당 공고의 **정정 전(원본) 공고**가 `announcements` 테이블에 이미 적재되어 있는지 검색합니다.
  - **미적재 시**: 일반 신규 공고로 취급하여 전체 적재 파이프라인(`extract-data` 스킬)을 적용합니다.
  - **기적재 시**: 본 `patch-correction` 스킬에 의거하여 부분 업데이트 프로세스에 진입합니다.

### 2단계: 메타데이터(`download_meta.json`)를 통한 정정사유 분석
* 정정공고의 로컬 디렉토리 내에 위치한 `download_meta.json` 파일을 열어 LH가 고지한 **정정 사유 텍스트**를 식별합니다.
  - 주로 `dsEtcInfo` 배열 내의 `PAN_DTL_CTS` 또는 `CRC_RSN` 필드에 기재되어 있습니다.
* 정정 사항의 성격(예: 임대보증금 및 대출 안내, 소득 제한 조건, 추가옵션 유의사항 등)에 따라 업데이트해야 할 기존 데이터베이스의 매핑 테이블(예: `announcement_details`, `announcement_schedules` 등)을 식별합니다.

### 3단계: 가상환경 하에서 정정공고 마크다운 단건 변환
* 전체 폴더 스캔으로 인한 오버헤드와 리소스 낭비를 막기 위해, 반드시 **가상환경(`venv`) 파이썬**을 지정하고 **해당 정정공고 PDF 경로를 정확히 파라미터로 명시**해 단건으로 마크다운 변환을 진행합니다.
  - **명령어 예시**: `.venv/bin/python .agents/scripts/convert_pdf_to_md.py docs/pdf/{공고_폴더}/{정정공고파일명}.pdf`

### 4단계: 마크다운 본문(`document.md`) 분석 및 원본 텍스트 발췌
* 변환된 `docs/md/{공고_폴더}/document.md` 파일에서 2단계에서 파악한 정정사유 관련 키워드를 추적하여, 새롭게 추가되거나 정정된 **원본 텍스트 본문(표, 리스트, 설명글 등)**을 정확하게 발췌합니다.

### 5단계: 업데이트 계획 선보고 및 사용자 승인 획득 (Critical)
* DB를 실제로 갱신하기 전에, 수정이 필요한 대상 테이블, 컬럼, 그리고 반영할 구체적인 정정 텍스트 내용을 요약하여 **사용자에게 먼저 보고하고 최종 실행 승인**을 요청합니다.
* 사용자의 명시적인 승인 지시가 떨어지기 전에는 절대로 실제 데이터베이스 데이터를 갱신(UPDATE/INSERT)하지 않습니다.

### 6단계: DB 덮어쓰기 업데이트 집행 및 검증
* 사용자의 승인을 득한 후, SQL 쿼리 또는 안전하게 파라미터 바인딩을 적용한 일회성 파이썬 패치 스크립트를 작성하여 데이터베이스를 업데이트합니다.
  - `announcements` 테이블의 `title` 필드를 최신 정정공고 제목(예: `[정정공고]...`)으로 업데이트합니다.
  - 5단계에서 지정한 상세 테이블의 컬럼 값을 발췌한 정정 텍스트로 덮어쓰거나 덧붙입니다.
* 업데이트 적용 후 즉시 검증용 `SELECT` 쿼리를 실행하여 데이터가 정합하고 정확하게 반영되었는지 육안으로 최종 검사합니다.

---

## 2. 주의 사항 및 예외 처리 규약

1. **가상환경 격리 원칙**:
   * 스크립트 실행 시 가상환경을 활성화하지 않거나, 단건 파라미터 지정을 생략하여 전체 변환을 제안하지 마십시오.

2. **일회성 패치 스크립트 완전 삭제**:
   * DB 업데이트를 위해 임시로 작성한 일회성 파이썬 패치 스크립트나 SQL 파일은 **작업 완료 및 사후 검증 즉시 파일 시스템에서 완전 삭제**하여 형상 관리를 오염시키지 않아야 합니다.

3. **지시된 과업 범위 준수**:
   * 데이터 정정 작업 시 지시된 테이블 및 데이터 이외의 다른 환경 설정이나 중요 시스템 설정을 자의적으로 수정하지 마십시오. 오직 정정공고의 변경 대상 내용에만 극도로 집중해야 합니다.

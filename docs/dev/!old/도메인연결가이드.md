Cloudflare에서 구매하신 `pleasehome.com` 도메인과 ncloud 서버를 연결하는 가이드입니다. Cloudflare는 DNS 반영 속도가 매우 빠르므로, 설정 후 거의 즉시 연결이 가능합니다.

---

## 1. ncloud 서버 공인 IP 확인

도메인과 연결할 서버의 외부 접속 IP 주소를 먼저 확인해야 합니다.

1. **ncloud 콘솔**에 로그인합니다.
2. **Services > Compute > Server** 메뉴로 이동합니다.
3. 보유하고 계신 서버 리스트에서 해당 서버의 **공인 IP(Public IP)** 주소를 복사하여 메모해 둡니다.
> **주의**: 실서비스 운영 시에는 서버 재시작 시 IP가 변경되지 않도록 **공인 IP(정적 IP)**를 신청하여 서버에 할당하시는 것을 권장합니다.



---

## 2. Cloudflare DNS 레코드 설정

구매하신 `pleasehome.com` 도메인의 DNS Zone에 ncloud 서버 IP를 등록하는 과정입니다.

1. **Cloudflare 대시보드**에 로그인합니다.
2. 메인 화면의 도메인 목록에서 `pleasehome.com`을 클릭합니다.
3. 왼쪽 사이드바 메뉴에서 DNS > 레코드(Records)를 선택합니다.
4. **레코드 추가(Add record)** 버튼을 클릭하고 아래와 같이 2개의 레코드를 추가합니다.

### [레코드 1] 루트 도메인 연결 (`pleasehome.com`)

* **유형(Type)**: `A`
* **이름(Name)**: `@` (입력 시 자동으로 `pleasehome.com`으로 변환됨)
* **IPv4 주소(IPv4 address)**: `복사한 ncloud 공인 IP`
* **프록시 상태(Proxy status)**:
* **프록시됨(Proxied, 주황색 구름)**: Cloudflare의 보안 및 CDN 기능을 사용합니다. (서버 실제 IP 숨김)
* **DNS 전용(DNS only, 회색 구름)**: IP 연결 기능만 수행합니다. SSL 인증서 설정 등 서버 내부 설정 테스트 단계라면 우선 'DNS 전용'으로 시작하는 것을 권장합니다.


* 저장(Save)을 클릭합니다.

### [레코드 2] 서브 도메인 연결 (`[www.pleasehome.com](https://www.pleasehome.com)`)

* **유형(Type)**: `A`
* **이름(Name)**: `www`
* **IPv4 주소(IPv4 address)**: `복사한 ncloud 공인 IP`
* **프록시 상태(Proxy status)**: 레코드 1과 동일하게 맞춤 (주황색 또는 회색 구름)
* 저장(Save)을 클릭합니다.

## 3. ncloud ACG(Access Control Group) 설정 확인

서버의 방화벽 규칙에서 웹 포트가 열려 있는지 확인합니다.

1. **ncloud 콘솔 > Server > ACG** 메뉴로 이동합니다.
2. 해당 서버에 적용된 ACG를 선택하고 **ACG 설정**을 클릭합니다.
3. 아래 규칙이 없는 경우 추가합니다.
* **프로토콜**: `TCP` | **접근 소스**: `0.0.0.0/0` | **허용 포트**: `80` (HTTP)
* **프로토콜**: `TCP` | **접근 소스**: `0.0.0.0/0` | **허용 포트**: `443` (HTTPS)
> **참고 (Cloudflare 프록시 사용 시)**: Cloudflare 프록시(주황색 구름)를 켜두는 경우, 향후 보안을 위해 ACG 접근 소스에 전체 대역(`0.0.0.0/0`) 대신 Cloudflare의 공식 IP 대역만 허용하도록 제한할 수도 있습니다.

## 4. 연결 확인

Cloudflare는 DNS 업데이트가 즉시 반영되는 편입니다. 웹 브라우저 주소창에 `pleasehome.com`을 입력하여 ncloud 서버에 웹 서버(Nginx, Apache 등) 페이지가 정상적으로 호출되는지 확인하시면 됩니다.
